================================================================================
  4A. VPS + NGINX  (Ubuntu 22.04 / Debian)
================================================================================

Maan lo aapka VPS IP hai:  884.55.55.66
Aur domain hai:            call.yourcompany.com

STEP 1 — DNS set karo (apne domain provider GoDaddy/Hostinger/Namecheap pe):

    Type: A    Host: call    Value: 884.55.55.66    TTL: 300

  (Root domain ke liye Host: @  use karo)

STEP 2 — VPS me login karo (SSH):

    ssh root@884.55.55.66

STEP 3 — Nginx install karo:

    apt update && apt install -y nginx
    mkdir -p /var/www/zentord
    chown -R $USER:$USER /var/www/zentord

STEP 4 — Apne LAPTOP se build upload karo:

    rsync -avz --delete dist/  root@884.55.55.66:/var/www/zentord/

  (Windows users: WinSCP ya FileZilla use kar sakte ho — dist/ ka content
   /var/www/zentord/ me daal do)

STEP 5 — Nginx config banao:

    nano /etc/nginx/sites-available/zentord

  Yeh paste karo:

    server {
      listen 80;
      server_name call.yourcompany.com;
      root /var/www/zentord;
      index index.html;

      # SPA fallback — har route index.html return karega (React Router)
      location / {
        try_files $uri $uri/ /index.html;
      }

      # Hashed assets ko 1 saal cache karo
      location ~* \.(?:js|css|woff2?|svg|png|jpg|jpeg|webp|ico)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
      }

      # index.html kabhi cache mat karo (taaki naya deploy turant dikhe)
      location = /index.html {
        add_header Cache-Control "no-cache, no-store, must-revalidate";
      }

      # Security headers
      add_header X-Frame-Options "SAMEORIGIN";
      add_header X-Content-Type-Options "nosniff";
      add_header Referrer-Policy "strict-origin-when-cross-origin";
      add_header Permissions-Policy "microphone=(self), camera=()";
    }

  Save (Ctrl+O, Enter, Ctrl+X).

STEP 6 — Enable + reload:

    ln -s /etc/nginx/sites-available/zentord /etc/nginx/sites-enabled/
    nginx -t                 # syntax check
    systemctl reload nginx

STEP 7 — Browser me kholo:  http://call.yourcompany.com
  (Abhi http hai — agle step me HTTPS lagayenge)

================================================================================
  4B. DOCKER / DOCKER COMPOSE
================================================================================

Repo root me  Dockerfile  banao:

    FROM oven/bun:1.1 AS build
    WORKDIR /app
    COPY package.json bun.lockb* ./
    RUN bun install --frozen-lockfile
    COPY . .
    RUN bun run build

    FROM nginx:1.27-alpine
    COPY --from=build /app/dist /usr/share/nginx/html
    COPY deploy/nginx.conf /etc/nginx/conf.d/default.conf
    EXPOSE 80

deploy/nginx.conf  me wahi server-block daalo jo section 4A ke STEP 5 me hai.

docker-compose.yml:

    services:
      web:
        build: .
        restart: unless-stopped
        ports: ["80:80"]

Run karo:

    docker compose up -d --build

Update karne ke liye:

    git pull
    docker compose up -d --build

================================================================================
  4C. cPanel / SHARED HOSTING (Hostinger, GoDaddy, Bluehost, etc.)
================================================================================

  1. Apne laptop pe:    bun run build
  2. dist/  folder ke ANDAR ke saare files select karo (folder nahi, andar ka content)
  3. cPanel -> File Manager -> public_html/ me upload karo
  4. public_html/  me  .htaccess  file banao aur yeh paste karo:

         <IfModule mod_rewrite.c>
           RewriteEngine On
           RewriteBase /
           RewriteRule ^index\.html$ - [L]
           RewriteCond %{REQUEST_FILENAME} !-f
           RewriteCond %{REQUEST_FILENAME} !-d
           RewriteRule . /index.html [L]
         </IfModule>

         <FilesMatch "index\.html$">
           Header set Cache-Control "no-cache, no-store, must-revalidate"
         </FilesMatch>

  5. cPanel se SSL enable karo (AutoSSL / Let's Encrypt button — free)
  6. Done. Browser me apna domain kholo.

  2. Build command:    bun run build

================================================================================
  6. HTTPS LAGAO  (Let's Encrypt — FREE, auto-renew)
================================================================================

VPS pe (root user):

    apt install -y certbot python3-certbot-nginx
    certbot --nginx -d call.yourcompany.com -d www.call.yourcompany.com
    systemctl enable --now certbot.timer

Done. 90 din me apne aap renew hoga.

⚠️ ZARURI: HTTPS ke BINA browser microphone access NAHI dega.
Iske bina calls kaam nahi karenge. Skip mat karna.

================================================================================
  7. FIREBASE GOOGLE LOGIN ENABLE KARO
================================================================================

  A. https://console.firebase.google.com pe project banao
  B. Authentication -> Sign-in method -> Google -> Enable
  C. Authentication -> Settings -> Authorized domains -> Add karo:
        call.yourcompany.com
        localhost
        <aapka lovable.app preview URL>
  D. Project Settings -> General -> Your apps -> Web app  ->  config copy karo:
        projectId, apiKey, authDomain, appId
  E. Apni site pe login karo as ADMIN -> Admin Panel -> Firebase tab
     -> 4 values paste karo -> "Enable Google sign-in" toggle ON -> Save

Bas. Redeploy nahi karna. Turant kaam karega.
Kabhi bhi off karna ho — wahi toggle off kar do.

================================================================================
  11. COMMON ERRORS AUR FIX
================================================================================

❌ "404 on page refresh"
   → Nginx me  try_files $uri $uri/ /index.html;  missing hai. Section 4A STEP 5 dekho.
   → cPanel pe .htaccess missing hai. Section 4C dekho.

❌ "Microphone permission denied"
   → HTTPS nahi laga. certbot run karo (Section 6).

❌ "Google login button kaam nahi karta"
   → Firebase Authorized domains me apna domain add karo (Section 7-C).
   → Admin Panel -> Firebase tab me "Enable" toggle on hai check karo.

❌ "Call connect nahi ho raha — 'Origin not allowed'"
   → Company ke Security tab me domain whitelist me apna site domain add karo.

❌ "Mixed content error" (browser console me)
   → HTTPS site se HTTP resource load ho raha. Saari URLs https:// honi chahiye.

❌ Audio choppy / one-way audio
   → User strict NAFT/firewall ke peeche hai. TURN server lagao.
     server.txt section 9 dekho (coturn setup).

❌ Admin password bhul gaye
   → server.txt section 12 dekho (3 recovery options).
