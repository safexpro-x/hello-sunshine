  2. DATABASE SCHEMA SETUP
================================================================================

Aapko saari tables, RLS policies, triggers, aur functions apne naye Supabase
me banane padenge. Iske 2 tarike hain:

OPTION A — Lovable se SQL nikal ke run karo (RECOMMENDED)
----------------------------------------------------------
  1. Lovable editor me  supabase/migrations/  folder kholo
  2. Saari .sql files ko DATE ORDER me sort karo (purani se nayi)
  3. Apne Supabase dashboard me jao -> SQL Editor -> "New query"
  4. Har migration file ka content paste karo, "Run" click karo
  5. Order ZARURI hai — purani migration pehle, nayi baad me

  Quick way (bulk):
     a. Local me clone karo:  git clone <your-repo>
     b. Terminal me:
            cat supabase/migrations/*.sql > /tmp/all_migrations.sql
        (ya Windows pe: type supabase\migrations\*.sql > C:\temp\all.sql)
     c. /tmp/all_migrations.sql ka content Supabase SQL Editor me paste -> Run

OPTION B — Supabase CLI se push karo (advanced users)
------------------------------------------------------
  1. Install:    npm install -g supabase
  2. Login:      supabase login
  3. Link:       supabase link --project-ref xxxxxxxx
  4. Push:       supabase db push

Verify karo:  Supabase dashboard -> Table Editor me yeh tables dikhne chahiye:
  ✓ companies, employees, calls, plans, subscriptions, payments
  ✓ profiles, user_roles, brand_settings, firebase_settings
  ✓ smtp_settings, razorpay_settings, site_content
  ✓ company_app_keys, company_domain_whitelist, company_ip_whitelist
  ✓ widget_slugs, email_outbox, email_verifications

  3. STORAGE BUCKETS SETUP
================================================================================

Supabase dashboard -> Storage -> "New bucket":

  Bucket name:  branding
  Public:       ✅ YES (logo/favicon publicly accessible hone chahiye)

Storage policies (SQL Editor me run karo):

    CREATE POLICY "Public read branding"
      ON storage.objects FOR SELECT
      USING (bucket_id = 'branding');

    CREATE POLICY "Admins upload branding"
      ON storage.objects FOR INSERT
      WITH CHECK (
        bucket_id = 'branding'
        AND public.has_role(auth.uid(), 'admin')
      );

    CREATE POLICY "Admins update branding"
      ON storage.objects FOR UPDATE
      USING (bucket_id = 'branding' AND public.has_role(auth.uid(), 'admin'));

    CREATE POLICY "Admins delete branding"
      ON storage.objects FOR DELETE
      USING (bucket_id = 'branding' AND public.has_role(auth.uid(), 'admin'));

  5. EDGE FUNCTIONS DEPLOY KARO
================================================================================

Frontend Lovable se direct kaam karega, lekin edge functions (backend logic)
aapko apne Supabase pe khud deploy karni padengi.

STEP 1 — Supabase CLI install:
    npm install -g supabase
    supabase --version    # verify

STEP 2 — Login:
    supabase login        # browser khulega, authorize karo

STEP 3 — Apna project link karo:
    cd zentord                                    # repo root
    supabase link --project-ref xxxxxxxx          # apna project ref daalo

STEP 4 — Saari functions ek saath deploy karo:
    supabase functions deploy --no-verify-jwt

  Ya ek-ek karke (recommended for first time):
    supabase functions deploy signup-request --no-verify-jwt
    supabase functions deploy verify-email --no-verify-jwt
    supabase functions deploy widget-bootstrap --no-verify-jwt
    supabase functions deploy call-start --no-verify-jwt
    supabase functions deploy employee-login --no-verify-jwt
    supabase functions deploy employee-queue --no-verify-jwt
    supabase functions deploy employee-fcm-register --no-verify-jwt
    supabase functions deploy notify-employees-on-call --no-verify-jwt
    supabase functions deploy ai-assistant --no-verify-jwt
    supabase functions deploy firebase-bridge --no-verify-jwt
    supabase functions deploy firebase-public-config --no-verify-jwt
    supabase functions deploy password-reset-request --no-verify-jwt
    supabase functions deploy password-reset-confirm --no-verify-jwt
    supabase functions deploy process-email-outbox --no-verify-jwt
    supabase functions deploy plan-expiry-check
    supabase functions deploy razorpay-create-order
    supabase functions deploy razorpay-verify-payment
    supabase functions deploy admin-update-self

NOTE: supabase/config.toml me jin functions ke liye  verify_jwt = false  hai,
unko  --no-verify-jwt  flag se deploy karo. Baki ke liye flag mat lagao.

STEP 5 — Cron job schedule karo (email outbox + plan expiry):

Supabase dashboard -> Database -> Extensions -> enable karo:
    ✓ pg_cron
    ✓ pg_net

Phir SQL Editor me run karo:

    SELECT cron.schedule(
      'process-email-outbox',
      '* * * * *',   -- har minute
      $$
      SELECT net.http_post(
        url := 'https://xxxxxxxx.supabase.co/functions/v1/process-email-outbox',
        headers := '{"Content-Type":"application/json","Authorization":"Bearer YOUR_SERVICE_ROLE_KEY"}'::jsonb
      );
      $$
    );

    SELECT cron.schedule(
      'plan-expiry-check',
      '0 */6 * * *',  -- har 6 ghante
      $$
      SELECT net.http_post(
        url := 'https://xxxxxxxx.supabase.co/functions/v1/plan-expiry-check',
        headers := '{"Content-Type":"application/json","Authorization":"Bearer YOUR_SERVICE_ROLE_KEY"}'::jsonb
      );
      $$
    );

  (xxxxxxxx aur YOUR_SERVICE_ROLE_KEY apne values se replace karo)

  8. ADMIN ACCOUNT CREATE KARNE KE 3 TARIKE
================================================================================

Yeh sabse important step hai. Admin ke bina aap kuch configure nahi kar paayenge.

═══════════════════════════════════════════════════════════════════════════════
  TARIKA 1 — Auto-admin trigger (SABSE EASY) ⭐ RECOMMENDED
═══════════════════════════════════════════════════════════════════════════════

Code me already ek trigger hai jo  admin@gmail.com  email se signup karne par
automatic admin role assign kar deta hai. Steps:

  1. Apni site kholo:    https://yourdomain.com/auth
  2. "Sign up" tab pe jao
  3. Yeh details daalo:
        Name:      Admin
        Email:     admin@gmail.com    ⬅️ EXACTLY yeh email
        Phone:     +91XXXXXXXXXX
        Password:  StrongPassword@123
  4. "Sign up" click karo
  5. Mail aayega (agar SMTP set hai) — verify link click karo
     Agar SMTP nahi set hai abhi, to step 5 skip karne ke liye:
        Supabase dashboard -> Authentication -> Users -> apna user dhundo
        -> "..." menu -> "Confirm email"
  6. Login karo with admin@gmail.com
  7. /admin pe jao — admin panel khul jayega ✅

Agar dusri email use karni hai to TARIKA 2 dekho.

═══════════════════════════════════════════════════════════════════════════════
  TARIKA 2 — Manual SQL se kisi bhi user ko admin banao
═══════════════════════════════════════════════════════════════════════════════

  1. Pehle normal signup karo apni desired email se (e.g. owner@yourcompany.com)
  2. Email verify karo (mail link ya Supabase dashboard se confirm)
  3. Supabase dashboard -> SQL Editor -> "New query":

        -- Apni user ID dhundo
        SELECT id, email FROM auth.users WHERE email = 'owner@yourcompany.com';

        -- Phir admin role assign karo (upar wali ID copy karke):
        INSERT INTO public.user_roles (user_id, role)
        VALUES ('PASTE-USER-ID-HERE', 'admin')
        ON CONFLICT DO NOTHING;

  4. Logout karke wapas login karo — ab admin role active hai
  5. /admin pe jao

═══════════════════════════════════════════════════════════════════════════════
  TARIKA 3 — Supabase dashboard se directly user create + admin
═══════════════════════════════════════════════════════════════════════════════

  1. Supabase dashboard -> Authentication -> Users -> "Add user" -> "Create new user"
        Email:           admin@yourcompany.com
        Password:        StrongPassword@123
        Auto-confirm:    ✅ YES
  2. User create hone ke baad uski ID copy karo
  3. SQL Editor me run karo:

        INSERT INTO public.user_roles (user_id, role)
        VALUES ('PASTE-USER-ID-HERE', 'admin');

        -- Profile bhi banao (agar trigger se nahi bana)
        INSERT INTO public.profiles (user_id, email, display_name, email_verified_at)
        VALUES ('PASTE-USER-ID-HERE', 'admin@yourcompany.com', 'Admin', now())
        ON CONFLICT (user_id) DO NOTHING;

  4. Site pe login karo, /admin kholo ✅

⚠️ SECURITY: Admin password STRONG rakhna. Admin panel me step-up password
re-confirmation laga hua hai, lekin pehla password leak hua to game over.
Ho sake to alag email use karo (admin@gmail.com common hai — guess hota hai).

================================================================================
  11. COMMON ERRORS AUR FIX
================================================================================

❌ "Failed to fetch" / CORS errors
   → Edge function deploy nahi hui. Section 5 se redeploy karo.

❌ "permission denied for table xxx"
   → RLS policy missing. Migration dobara run karo (Section 2).

❌ Signup karne par mail nahi aa raha
   → SMTP settings galat hain. Admin panel me test karo.
   → Cron job nahi chal raha. Section 5 step 5 dekho.

❌ "Not an active employee" error
   → User_roles table me entry missing. SQL se add karo:
        INSERT INTO public.user_roles (user_id, role)
        VALUES ('user-id', 'employee');

❌ Admin panel khulta nahi
   → user_roles me 'admin' role missing. TARIKA 2 ya 3 use karo.

❌ "Cannot find module" type errors frontend pe
   → bun install dobara chalao, phir bun run build.

❌ Edge function "secret not found"
   → Section 4 ke saare required secrets set karo.

❌ Google login kaam nahi karta
   → Firebase authorized domains me apna domain add karo.
   → Admin panel -> Firebase tab -> "Enable" toggle ON karo.
